# Raiderade – Campus Water Fountain Finder

Raiderade is a simple web application designed to help students quickly find reliable water fountains across campus. Many students rely on water fountains daily, yet often encounter issues like warm water, poor flow, metallic taste, or expired filters. Raiderade solves this by providing accessible, reliable information about campus buildings and fountain locations.

## 🚀 Features
- Interactive campus map
- List of major campus buildings
- Search functionality for buildings and facilities
- Guest mode and account screen UI
- Mobile-friendly, lightweight design

## 📘 How to Use
1. Open `index.html` in any browser.
2. Start on the "Welcome Screen".
3. Continue as a guest or navigate to the "Account" page.
4. Select a building or use the "map search bar" to explore fountain locations.
